 # Задание 2 — API-пайплайн: данные → LLM → результат

Скрипт читает отзывы покупателей из CSV-файла, отправляет каждый отзыв в LLM через Groq API и сохраняет структурированный результат в JSON.

## Задача

Классификация отзывов: скрипт читает отзывы → LLM определяет тональность и основную тему каждого отзыва → результат сохраняется в JSON.

Для каждого отзыва модель определяет:

* тональность (`positive`, `negative`, `neutral`);
* основную тему отзыва.

## Запуск

Установить зависимости:

```bash
pip install -r requirements.txt
```

Создать файл `.env` с ключом:

```env
GROQ_API_KEY=your_api_key_here
MODEL=llama-3.3-70b-versatile
```

Подготовить файл `reviews.csv` с колонками:

```csv
id,review
```

Запустить скрипт:

```bash
python main.py
```

Результат сохраняется в файл:

```text
results.json
```

## Пример входных данных

Файл `reviews.csv`:

```csv
id,review
1,"Телефон отличный, батареи хватает почти на два дня."
2,"Очень плохое качество. Через неделю перестал включаться."
3,"Доставка пришла вовремя, товар соответствует описанию."
```
